# こちら、電脳ワークス！ Episode 0

改訂94の全43ページを収録した静的サイトです。マンガ画像は原稿と同じ寸法で、配信用のWebPに変換しています。

## 手元で確認

`docs/index.html` をブラウザで開いてください。HTTPで確認する場合はリポジトリのルートで `python -m http.server --directory docs 8000` を実行し、`http://localhost:8000/` を開きます。読みかけの位置は同じブラウザの同じ配信元に保存されます。HTMLファイルを直接開いた場合の保存の可否はブラウザによって異なります。

## GitHub Pagesで公開

`docs` フォルダーをそのまま `bemyselfkt/DennoWorks` の `main` ブランチに追加します。GitHubの **Settings → Pages** で **Deploy from a branch** を選び、 **main /docs** を指定して保存します。既定の公開URLは `https://bemyselfkt.github.io/DennoWorks/` です。

個別ページへのリンクは `reader.html#p09` の形式です。縦スクロール表示で開く場合は `reader.html#vertical-p09` を使います。
